# Sn2026 – Модульный инструмент для атаки на Telegram 

## Возможности
- Массовая отправка кодов восстановления (вызывает спам-блок номера)
- Веб-жб через браузер (undetected-chromedriver) с ручным вводом капчи
- Масс-репорты через Telethon от пула «прогретых» аккаунтов (папка sessions/)

## Установка
1. Установите Python 3.11+, Chrome/Chromium
2. pip install -r requirements.txt
3. Поместите .session файлы аккаунтов в папку sessions/ (минимум 4-5)
4. (Опционально) Создайте proxy_list.txt – по одному прокси на строку (IP:PORT)
5. Запустите python main.py

## Важно
- Для обхода капчи в веб-жб требуется ручной ввод (или добавьте ключ 2captcha в config.py)
- Атака кодами агрессивна – используйте с осторожностью
- Telethon-репортер требует авторизованных сессий с хорошей репутацией.
